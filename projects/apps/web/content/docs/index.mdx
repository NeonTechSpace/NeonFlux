## What you can do

NeonFlux currently lets you:

- change the command prefix and use the help and ping commands
- view message activity, member changes, and invite attribution
- build, preview, and send messages from the dashboard
- create reaction-role panels with independent or exclusive choices
- view, back up, compare, and deploy reviewed server layouts

## Dashboard routes

Open `/dashboard` to choose an installed community you can manage. A selected community is managed at `/dashboard/{guildId}`.

| Surface             | Implemented tools                        |
| ------------------- | ---------------------------------------- |
| Overview            | Growth and message-activity summaries    |
| Create & Deliver    | Message Builder, Reaction Roles          |
| Insights & Activity | Audit Events                             |
| Server Blueprint    | Overview, Backups, Compare, Deploy, Runs |
| Settings            | Command Prefix                           |

Features not listed here are not shipped dashboard routes.

## Dashboard behavior

The selected server and current feature remain visible while dashboard pages load.
Saved content stays visible during background updates, and a failed section can be retried without reloading the whole page.

## Security boundaries

Sign in with Fluxer to use the dashboard.
NeonFlux checks that you can manage a server before showing its data or making a change.

The bot token stays with the bot service and is never sent to your browser.

## Activity accuracy

Each message and member join is counted once when Fluxer supplies enough information to identify it.
Member leaves can be counted more than once if Fluxer repeats a leave notification because those notifications do not include a unique event ID.

Activity tracking does not delay bot commands.
An activity event may be missing from the dashboard if NeonFlux is overloaded or cannot save it.
